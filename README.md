# mi-CRM-VibeCoder

Landing comercial de **Nexo CRM**: gestión de clientes, venta de productos digitales y captación de leads desde redes sociales. Estilo minimalista con modo claro/oscuro.

## Ejecutar en local

```bash
npm start
```

Abre http://localhost:3000

## Desplegar en Railway

1. En Railway: **New Project → Deploy from GitHub repo** y elige este repositorio.
2. Railway detecta Node y ejecuta `npm start` automáticamente (usa la variable `PORT`).
3. En **Settings → Networking** pulsa **Generate Domain** para obtener la URL pública.
